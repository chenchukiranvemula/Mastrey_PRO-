14. NON-REPEATING QUESTION ENGINE

Create a persistent question history system.

This feature must be a priority.

Every question should have a unique identifier.

Track question history separately for each user.

Maintain:

- Questions seen
- Questions attempted
- Questions answered correctly
- Questions answered incorrectly
- Questions skipped
- Questions bookmarked
- Last attempt date
- Attempt count
- Performance history

Default test-generation rules

- Do not repeat questions within a test.
- Avoid questions previously seen by the student.
- Avoid near-duplicate questions.
- Avoid reusing identical question wording.
- Avoid generating the same question with only changed numbers.
- Generate new questions testing different conceptual approaches.
- Maintain a balanced distribution of topics.
- Maintain the requested difficulty.
- Do not select unverified questions.
- Respect examination patterns.

If the question bank is insufficient, tell the user that the available question pool is limited. Never falsely claim that all questions are new.

Revision mode exception

Users may intentionally select:

- Repeat wrong questions
- Repeat bookmarked questions
- Repeat previously attempted questions
- Revise all previous questions

The repetition prevention must be configurable, with revision mode explicitly overriding it.

Similarity detection

Implement duplicate detection through:

- Normalized text comparison
- Question fingerprints
- Similarity checking
- Concept and structure similarity
- Duplicate answer/solution checking

AI-generated questions should be checked before being added to the question bank.

18. AI QUESTION AND SOLUTION VALIDATION

Accuracy is essential.

AI responses must not be presented as guaranteed correct.

Implement the best feasible validation pipeline.

For AI-generated questions:

1. Generate question.
2. Generate answer.
3. Generate detailed solution.
4. Validate mathematical consistency.
5. Check answer against the solution.
6. Check duplicate similarity.
7. Validate question format.
8. Check examination suitability.
9. Flag uncertain content.
10. Store only after successful validation, or clearly mark it as unverified.

For mathematics and numerical questions, use a suitable computational validation system where feasible.

For educational theory:

- Validate against trusted reference content.
- Prioritize official syllabi, textbooks and verified materials.
- Do not invent citations.
- Do not fabricate official questions.

Provide a Report Incorrect Question / Report AI Error option.
